## V1.0 — 基础检测系统 (2025-01-15)

| 属性 | 内容 |
|------|------|
| **发布日期** | 2025-01-15 |
| **代号** | Foundation |
| **Git标签** | v1.0.0 |

### 核心功能
- ✅ YOLOv5图像缺陷检测（5类：崩边/溢胶/油污/坑洞/划痕）
- ✅ PyQt5桌面GUI（`Main.py` + `Ui_MainWindow.py`）
- ✅ 用户登录系统（`Login.py`）
- ✅ 图片检测模块（`imageDetect.py`）
- ✅ ABC等级自动判定（`abcJudgment.py`）
- ✅ MySQL检测结果存储（`plank_innovate`库）

### 技术栈
- PyTorch 2.0.1+cu117 / YOLOv5 / OpenCV 4.10
- PyQt5 5.15.11 / mysql-connector-python 8.1.0
- Python 3.8

### 已知问题
- 🐛 视频检测不支持（下一版本规划）
- 🐛 无Web可视化看板
- 🐛 检测报告仅支持手动导出Excel
- 🐛 中文路径下图片读取偶发失败


1. 🔮 **微服务化架构**：检测服务 / 数据服务 / 报告服务 / 用户服务
