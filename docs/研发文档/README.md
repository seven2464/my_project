## 项目速览

### 系统简介
板探智眸（玻影智鉴）是一套基于深度学习的工业板材缺陷智能检测系统，支持对玻璃面板进行5大类缺陷（崩边、溢胶、油污、坑洞、划痕）的自动检测、ABC等级判定、损伤程度评估，并自动生成含AI分析的检测报告。

### 核心技术栈
- **检测模型**：YOLOv5m + Transformer注意力（mAP 90.7%）
- **分割模型**：U-Net + CBAM注意力（IoU 82.5%）
- **推理加速**：TensorRT FP16（9.5ms/张）
- **桌面界面**：PyQt5（Main.py 117KB + Ui_MainWindow.py 95KB）
- **Web看板**：Flask + ECharts（7个API接口）
- **AI分析**：讯飞星火Spark大模型 v3.5
- **数据库**：MySQL 8.0（plank_innovate库）
- **报告生成**：python-docx + docx2pdf
