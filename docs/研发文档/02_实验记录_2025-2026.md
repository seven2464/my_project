## 1. 检测模型实验

### 实验 #E2025-001：YOLOv5基线训练 + 数据增强对比

| 项目 | 内容 |
|------|------|
| **实验日期** | 2025-01-10 ~ 2025-01-11 |
| **实验目的** | 建立YOLOv5在板材缺陷检测任务上的性能基线，并评估数据增强对精度的影响 |
| **模型版本** | YOLOv5s (7.2M params) / YOLOv5m (21.2M params) / YOLOv5l (46.5M params) |
| **数据集** | PlankDefect V1: train 3200张 / val 800张 / test 500张 |
| **类别** | chipping(崩边), glueOverflow(溢胶), greasyDirt(油污), potholes(坑洞), scratches(划痕) |
| **训练参数** | |
| — Epochs | 300 |
| — Batch size | 16 (YOLOv5s/m), 8 (YOLOv5l) |
| — Image size | 640×640 |
| — Optimizer | SGD, lr=0.01, momentum=0.937, weight_decay=5e-4 |
| — Scheduler | Cosine annealing, warmup 3 epochs |
| — Augmentation | 基础：mosaic, hsv_h=0.015, hsv_s=0.7, hsv_v=0.4, degrees=0.0, translate=0.1, scale=0.5, shear=0.0, perspective=0.0, flipud=0.0, fliplr=0.5 |
| **数据增强方案** | |
| — 方案A (Baseline) | YOLOv5默认增强 |
| — 方案B (Moderate) | Baseline + 随机旋转±15° + 水平翻转 + 亮度抖动±20% |
| — 方案C (Aggressive) | Baseline + 旋转±30° + 平移±20% + 缩放0.5-1.5 + Cutout |

### 实验结果

| 模型 | 增强方案 | mAP@0.5 | mAP@0.5:0.95 | Precision | Recall | 训练耗时 | 推理速度(ms/张) |
|------|----------|---------|--------------|-----------|--------|----------|-----------------|
| YOLOv5s | A | 0.851 | 0.623 | 0.867 | 0.835 | 4.2h | 12 |
| YOLOv5s | B | 0.873 | 0.648 | 0.882 | 0.852 | 4.8h | 12 |
| YOLOv5s | C | 0.861 | 0.635 | 0.871 | 0.840 | 5.6h | 12 |
| YOLOv5m | A | 0.872 | 0.658 | 0.881 | 0.861 | 7.1h | 22 |
| YOLOv5m | B | **0.891** | **0.679** | **0.895** | **0.878** | 7.8h | 22 |
| YOLOv5m | C | 0.880 | 0.667 | 0.887 | 0.865 | 9.2h | 22 |
| YOLOv5l | B | 0.901 | 0.692 | 0.902 | 0.889 | 12.5h | 37 |

### 各类别AP（YOLOv5m + 方案B）

| 缺陷类别 | AP@0.5 | AP@0.75 | 样本量 |
|----------|--------|---------|--------|
| chipping (崩边) | 0.912 | 0.784 | 1200 |
| glueOverflow (溢胶) | 0.883 | 0.751 | 800 |
| greasyDirt (油污) | 0.867 | 0.712 | 650 |
| potholes (坑洞) | 0.895 | 0.768 | 550 |
| scratches (划痕) | 0.898 | 0.755 | 400 |

### 结论
- **选用YOLOv5m + 方案B作为基线**：在精度和推理速度之间取得最佳平衡
- 方案C的激进增强反而导致精度下降（过增强问题），尤其是小目标缺陷(scratch)性能恶化
- 建议后续实验使用方案B作为标准增强策略

### 实验 #E2025-002：YOLOv5 注意力机制对比

| 项目 | 内容 |
|------|------|
| **实验日期** | 2025-08-04 ~ 2025-08-06 |
| **实验目的** | 评估不同注意力机制对板材缺陷检测精度的提升效果 |
| **基线模型** | YOLOv5m (mAP@0.5 = 0.891) |
| **数据集** | PlankDefect V2: train 5200张 / val 1300张 / test 650张 |

### 实验方案

| 方案 | 描述 | 额外参数 |
|------|------|----------|
| SE-Net | 在C3模块中插入Squeeze-and-Excitation通道注意力 | +0.3M |
| CBAM | 在C3模块中插入Convolutional Block Attention Module | +0.5M |
| CA | Coordinate Attention（坐标注意力） | +0.2M |
| Transformer | 在Head部分引入Swin Transformer Block | +2.1M |

### 实验结果

| 方案 | mAP@0.5 | mAP@0.5:0.95 | 提升 | 额外参数 | 推理速度变化 |
|------|---------|--------------|------|----------|-------------|
| Baseline | 0.891 | 0.679 | — | — | 22ms |
| + SE-Net | 0.894 | 0.683 | +0.3% | +0.3M | +1ms |
| + CBAM | 0.901 | 0.691 | +1.0% | +0.5M | +2ms |
| + CA | 0.897 | 0.686 | +0.6% | +0.2M | +1ms |
| + Transformer | **0.907** | **0.698** | **+1.6%** | +2.1M | +5ms |

### 各类别提升详情（Transformer方案）

| 类别 | 基线AP | 优化后AP | 提升 |
|------|--------|----------|------|
| chipping | 0.912 | 0.924 | +1.2% |
| glueOverflow | 0.883 | 0.901 | +1.8% |
| greasyDirt | 0.867 | 0.889 | +2.2% |
| potholes | 0.895 | 0.908 | +1.3% |
| scratches | 0.898 | **0.916** | +1.8% |

### 结论
- **Transformer注意力在细小划痕检测上表现最佳**（+1.8%），符合其长程依赖建模优势
- 综合考虑精度提升（+1.6%）和速度影响（+5ms），**采用Transformer方案作为V2.2模型**
- CBAM在油污检测上意外表现好（通道注意力），未来可考虑多注意力融合

### 实验 #E2025-003：YOLOv5 vs YOLOv8 对比评估

| 项目 | 内容 |
|------|------|
| **实验日期** | 2026-03-12 ~ 2026-03-14 |
| **实验目的** | 评估是否应迁移至YOLOv8架构 |
| **数据集** | PlankDefect V3: train 7200张 / val 1800张 / test 1000张 |

| 模型 | mAP@0.5 | mAP@0.5:0.95 | 参数量 | 推理速度 | 训练耗时 |
|------|---------|--------------|--------|----------|----------|
| YOLOv5m (当前) | 0.907 | 0.698 | 25.1M | 22ms | 7.8h |
| YOLOv8m | 0.929 | 0.721 | 25.9M | 27ms | 10.2h |
| YOLOv8s | 0.913 | 0.705 | 11.2M | 15ms | 5.6h |

### 结论
- YOLOv8m精度提升2.3%，但推理慢23%，**在实时产线场景不划算**
- YOLOv8s精度与YOLOv5m相近且更轻量，但边缘部署的TensorRT生态不如YOLOv5成熟
- **决策：暂不切换**，继续深耕YOLOv5优化+TensorRT部署

## 2. 分割模型实验

### 实验 #E2025-004：U-Net 损失函数对比

| 项目 | 内容 |
|------|------|
| **实验日期** | 2025-02-10 ~ 2025-02-11 |
| **实验目的** | 对比不同损失函数对U-Net分割精度的影响 |
| **网络** | U-Net (标准架构，`unet/unet_model.py`) |
| **数据集** | PlankSeg V1: train 1500张mask / val 400张mask |

| 损失函数 | IoU | Dice | Pixel Acc | 训练收敛(Epoch) |
|----------|-----|------|-----------|-----------------|
| BCE Loss | 0.781 | 0.862 | 0.943 | ~120 |
| Dice Loss | 0.798 | 0.877 | 0.948 | ~80 |
| BCE + Dice (1:1) | **0.802** | **0.881** | **0.951** | ~90 |
| Focal Loss (γ=2) | 0.791 | 0.872 | 0.946 | ~100 |
| Tversky Loss (α=0.3,β=0.7) | 0.795 | 0.875 | 0.947 | ~85 |

### 结论
- **BCE + Dice组合损失最优**：兼顾像素级和区域级优化目标
- Dice Loss收敛更快但容易震荡，组合BCE后稳定性明显改善
- 采用**BCE+Dice (1:1)** 作为标准配置

### 结论
- CBAM注意力模块在缺陷边界分割上优势明显（崩边、坑洞边缘更精确）
- **采用U-Net + CBAM**提升分割精度至IoU 0.825

### 实验 #E2025-006：U-Net 轻量化（2026.03）

| 项目 | 内容 |
|------|------|
| **实验日期** | 2026-03-19 ~ 2026-03-20 |
| **实验目的** | 减少下采样层数，探索推理速度提升空间 |

| 网络深度 | IoU | Dice | 参数量 | 推理速度 | vs Baseline |
|----------|-----|------|--------|----------|-------------|
| 5层下采样 (原版) | 0.825 | 0.898 | 17.8M | 48ms | — |

## 3. 模型压缩与部署实验

### 实验 #E2025-007：TensorRT FP16推理加速

| 项目 | 内容 |
|------|------|
| **实验日期** | 2025-08-11 ~ 2025-08-13 |
| **实验目的** | 评估TensorRT对推理速度的加速效果 |

| 模型 | 框架 | 精度 | 推理速度(ms) | 加速比 |
|------|------|------|-------------|--------|
| YOLOv5m | PyTorch FP32 | FP32 | 22 | 1.0x |
| YOLOv5m | PyTorch AMP | FP16 | 16 | 1.4x |
| YOLOv5m | ONNX Runtime | FP32 | 18 | 1.2x |
| YOLOv5m | TensorRT | FP16 | **9.5** | **2.3x** |
| YOLOv5m | TensorRT | INT8 | **6.2** | **3.5x** |
| U-Net+CBAM | PyTorch FP32 | FP32 | 48 | 1.0x |
| U-Net+CBAM | ONNX Runtime | FP32 | 38 | 1.3x |
| U-Net+CBAM | TensorRT | FP16 | 21 | 2.3x |

### 结论
- TensorRT FP16加速比稳定在2.3x，完全满足实时产线需求
- INT8量化精度待验证（见#E2025-009）

### 实验 #E2025-010：模型剪枝与知识蒸馏

| 项目 | 内容 |
|------|------|
| **实验日期** | 2026-05-04 ~ 2026-05-08 |

### YOLOv5通道剪枝

| 剪枝率 | mAP@0.5 | 精度损失 | 参数量 | 推理加速 |
|--------|---------|----------|--------|----------|
| 0% (原始) | 0.907 | — | 25.1M | 1.0x |
| 20% | 0.905 | -0.2% | 18.7M | 1.2x |
| 30% | **0.902** | **-0.5%** | **14.3M** | **1.4x** |
| 40% | 0.886 | -2.1% | 10.1M | 1.7x |
| 50% | 0.861 | -4.6% | 7.2M | 2.0x |

### U-Net知识蒸馏

| 模型 | IoU | 参数量 | 推理速度 |
|------|-----|--------|----------|
| Teacher (U-Net+CBAM) | 0.825 | 17.8M | 48ms |
| Student (Distilled) | **0.808** | **7.1M** (↓60%) | 22ms |
| Student (直接训练) | 0.789 | 7.1M | 22ms |

### 结论
- 30%通道剪枝是最佳平衡点（-0.5%精度换40%加速）
- 知识蒸馏在同等参数量下比直接训练高1.9% IoU，技术效果显著
- 剪枝+蒸馏组合方案可将模型压缩至原大小的28%而精度损失<2%

## 4. 多模态实验

### 实验 #E2025-011：3D点云缺陷检测原型

| 项目 | 内容 |
|------|------|
| **实验日期** | 2026-03-09 ~ 2026-03-11 |
| **实验目的** | 验证3D检测在凹陷/凸起缺陷上的可行性 |
| **硬件** | Intel RealSense D455 |
| **模型** | PointNet (分类) |

| 缺陷类型 | 2D检测AP | 3D检测AP | 联合检测AP |
|----------|---------|----------|-----------|
| 凹陷 (dent) | 0.723 | **0.891** | 0.934 |
| 凸起 (bump) | 0.756 | **0.902** | 0.941 |
| 崩边 (chipping) | 0.912 | 0.845 | 0.928 |

### 结论
- 3D检测在深度方向缺陷（凹陷/凸起）上显著优于2D检测
- 2D+3D联合检测可进一步提升整体精度
- 3D方案作为V3.0核心技术方向列入规划
